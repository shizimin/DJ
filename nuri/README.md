# Nuri — AI 付きの軽量ペイントアプリ (Mac 向け)

CLIP STUDIO PAINT の「よく使う部分」と AI 機能をひとつにまとめたお絵描きアプリです。
**Nano Banana Pro (Gemini 3 Pro Image)** と **GPT Image** をアプリの中から直接使え、
**CLIP STUDIO の .clip ファイル・ブラシ (.sut)・素材** を読み込めます。

ブラウザ技術 (TypeScript + Canvas) で作られていて、Mac の Chrome / Safari / Edge で動きます。
Apple Pencil を使えば iPad の Safari でも描けます。

## できること

### 描く
- ペン・入り抜きペン・鉛筆・水彩・エアブラシ・マーカー (筆圧でサイズ / 濃さ、**入り抜き**、手ブレ補正、Shift+クリックで直線)
- 線は入力点の間を曲線でなめらかにつなぎ、ペンを離した位置まで手ブレ補正の遅れを追いつかせます。**筆圧の硬さ**も調整できます
- 消しゴム、塗りつぶし (他レイヤー参照・隙間を広げる)、スポイト (Option+クリック)
- 選択範囲 (矩形・投げなわ・自動選択)、レイヤー移動
- レイヤー: 17 種類の合成モード、不透明度、**クリッピング**、透明ピクセル保護、ロック、並べ替え、結合
- **レイヤーフォルダ**: 入れ子・開閉・「通過」合成・ドラッグでフォルダへ出し入れ・フォルダごと非表示/不透明度・フォルダを 1 枚に統合・⌘G でフォルダにまとめる
- 拡大縮小・回転・手のひら (トラックパッドのピンチ / 2 本指スクロール対応)
- 取り消し・やり直し

### AI (右パネルの「AI」タブ)
結果は常に**新しいレイヤー**として追加されるので、元の絵は壊れません (⌘Z で取り消しも可)。
生成中も描き続けられます。

| 機能 | 内容 |
|---|---|
| **背景生成** | 「キャラの後ろに描く」: 今の絵を AI に見せて、構図・光・画風を合わせた背景を作り、用紙のすぐ上に入れます。「背景だけ生成」: 文章から背景を作ります。キャンバスの縦横比に自動で合わせます。 |
| **写真の線画化** | 写真を読み込み → 線の太さ・描き込み量・用途 (キャラ / 背景 / スケッチ) を選んで線画化。白が透明になった線だけのレイヤーが写真の上に入ります。**ローカル (無料)** モードなら AI を使わずその場で輪郭を抽出します。 |
| **描き直し** | 投げなわで範囲を選び、「右手にカップを持たせる」などと指示すると、その範囲だけ描き直します。 |

AI は **Nano Banana Pro** (`gemini-3-pro-image-preview`) と **GPT Image** (`gpt-image-2` など) を切り替えられます。モデル名は自由に書き換えられます。

### CLIP STUDIO のファイル・素材
| 種類 | 読み込み方 | 内容 |
|---|---|---|
| **.clip** | 「開く」またはドロップ | ラスターレイヤーを、**フォルダ構成**・名前・表示・不透明度・合成モード・クリッピング・レイヤーマスク・用紙色ごと読み込みます。 |
| **.sut / .sutg (ブラシ)** | ドロップ / 「開く」 | サイズ・不透明度・濃さ・硬さ・間隔・筆圧設定・手ブレ補正と、**ブラシ先端の画像**を読み込みます。 |
| **素材 (.layer)** | 素材タブ → 「CSP 素材フォルダ」 | ダウンロードした素材 (画像・トーン・テクスチャ) を取り込み、クリックで貼り付けられます。 |
| **PSD** | 「開く」 / 「保存」 | フォルダとレイヤーを保ったままクリスタとやり取りできます (クリスタで PSD を開く / PSD で書き出す)。 |

Mac では素材は次の場所にあります。素材タブの「📁 CSP 素材フォルダ」でこのフォルダを選び、選択画面で ⌘⇧G を押してパスを貼り付けます。

```
~/Library/CELSYS/CLIPStudioCommon/Material
```

## 起動方法 (Mac)

1. [Node.js](https://nodejs.org/ja/download) (LTS) をインストール
2. `nuri` フォルダの **`start.command`** をダブルクリック
   (初回だけ準備に 1〜2 分かかります。ブラウザで `http://localhost:5178` が開きます)
3. 右パネルの **AI → 設定** で API キーを入力
   - Nano Banana Pro: [Google AI Studio](https://aistudio.google.com/apikey) (有料枠が必要)
   - GPT Image: [OpenAI Platform](https://platform.openai.com/api-keys)

Chrome / Edge ではアドレスバーの「インストール」ボタンで、Safari では「ファイル → Dock に追加」で、アプリのように独立したウィンドウで使えます。

> API キーはこの Mac のブラウザ内 (localStorage) にだけ保存され、Google / OpenAI 以外には送られません。
> 利用料金は各社の API 料金がかかります。

## ショートカット

| キー | 動作 | キー | 動作 |
|---|---|---|---|
| B / E / G / I | ペン / 消しゴム / 塗りつぶし / スポイト | ⌘Z / ⇧⌘Z | 取り消し / やり直し |
| M / L / W | 矩形 / 投げなわ / 自動選択 | ⌘A / ⌘D / ⇧⌘I | 全選択 / 解除 / 反転 |
| V / H / Space | 移動 / 手のひら / 一時的に手のひら | Delete / ⌥Delete | 消去 / 描画色で塗る |
| [ / ] | ブラシサイズ | ⇧⌘N / ⌘E | 新規レイヤー / 下に結合 (フォルダは統合) |
| | | ⌘G | フォルダにまとめる |
| R / Q | 回転 | ⌘0 / ⌘1 | 全体表示 / 100% |
| X | 白と描画色の切り替え | ⌘S / ⇧⌘E | PSD 保存 / PNG 書き出し |

## 制限事項

- **.clip の書き出しはできません** (形式が非公開のため)。クリスタへ戻すときは PSD で保存してください。
- .clip の **色調補正レイヤー・レイヤー効果 (フチ取りなど)・3D** は読み込まれません。ベクター / テキストレイヤーはクリスタが保存したラスター画像として読み込みます。フォルダのマスクは中のレイヤーに適用した状態で読み込みます。
- 一部の合成モード (焼き込みリニア・ビビッドライト・除算など) は近いモードに置き換えます。
- .sut ブラシの **テクスチャ・デュアルブラシ・水彩の混色・散布の細かい設定** は再現しません。描き味はクリスタと同じにはなりません。
- 素材ファイルは一部が暗号化されており、読める部分から画像を復元しています。読めない素材は取り込み時に件数を表示します。
- レイヤーはキャンバス全体の大きさで持つため、A4 350dpi で数十枚を超えるとメモリを多く使います。
- AI の結果の品質・料金・利用規約は各社のサービスに従います。

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm test           # 単体テスト
npm run build      # 型チェック + ビルド
npm run e2e        # 実ブラウザでの動作確認 (AI はモック)
```

CLIP STUDIO のファイル形式は公開されていないため、オープンソースの解析結果
([dobrokot/clip_to_psd](https://github.com/dobrokot/clip_to_psd) など) を参考に独自に実装しています。
実ファイルでの確認は `NURI_FIXTURES=<サンプルのあるディレクトリ> npm test` / `npm run e2e -- <ディレクトリ>` で行えます
(サンプルはライセンスの都合でリポジトリに含めていません)。
